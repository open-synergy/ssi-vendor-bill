# Deactivate Vendor Bill Type

## Pre-Condition

- None.

## Flow

1. Open the **Financial Accounting > Configuration > Vendor Bill Types** menu.
2. Select one or more records to deactivate (check the checkbox).
3. Click **Action** > **Archive**.
4. Click **OK** to confirm.

## Post-Condition

- The records are archived and no longer appear in the default list view.
- Deactivated types cannot be selected as **Type** on new vendor bills.
- Existing vendor bills that already use this type are not affected.
